⚙️ SHA-256 Hash Generation Process

1

Input Message

The original text is provided as input to the SHA-256 algorithm.

2

Convert to Binary

Each character is converted into its binary representation using UTF-8 encoding.

3

Padding

Extra bits are added to make the message length suitable for SHA-256 block processing.

4

512-Bit Blocks

The padded message is divided into blocks of 512 bits.

5

64 Processing Rounds

Mathematical operations are repeatedly performed using XOR, AND, rotations and additions.

6

256-Bit Hash Output

The final output is a fixed-size 256-bit hash, represented using 64 hexadecimal characters.

🛡️ Important Properties of SHA-256

🔒

One-Way Function

It is computationally difficult to recover the original message from the hash.

🎯

Fixed Length

Every input produces a 256-bit output regardless of input size.

🌊

Avalanche Effect

A tiny change in input causes a major change in the resulting hash.

🧬

Unique Fingerprint

SHA-256 creates a cryptographic fingerprint for data integrity and security.
